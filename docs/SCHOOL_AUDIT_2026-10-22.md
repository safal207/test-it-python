# AI PATH: аудит школы и пакет проверки изменений

Дата: 22 октября 2026, Москва. Цель — сделать выбор обучения, просмотр проектов и работу с учебными инструментами понятнее, сохранив 23 программы, восемь курсов по нейросетям и реальные источники изображений.

Исходный аудит завершён. Это **снимок наблюдений до исправлений с планом проверки новой версии**. Статус выпуска пока `INCOMPLETE / BLOCK`: обязательные проверки новой версии ещё не привязаны к её точному коммиту. Уровень доказательств — `F2`, глубина — `STANDARD`, проверка выпуска — `L4`. Статус не означает запрет на уже разрешённые пользователем исправления; он запрещает считать непроведённые проверки успешными.

Три главных изменения: честное сохранение рабочей тетради, доступная навигация на телефоне и более ясный первый экран с крупными примерами работ.

## Версия и границы

Исходный коммит: `54a9e87cbcf7a7aed45451ad7a2ee92af00e344b`; дерево: `a0d7af00545fedc0e1e98aef5953cc1bd0b4827e`. Репозиторий: [safal207/test-it-python](https://github.com/safal207/test-it-python). Публичная школа: [AI PATH](https://safal207.github.io/test-it-python/ai-path/).

`dist/ai-path` содержит публикуемые статические исходники. Материалы курсов по нейросетям имеют отдельную проверку соответствия генератору. Наблюдения опубликованного сайта записаны отдельно: они не заменяют проверку совпадения файлов с Git-коммитом.

Проверяются путь от первого экрана к программе, каталог и подбор, план и черновик обращения, учебные материалы, тетрадь исследования профессий, портфолио и интерактивные примеры. Внешние заявки, оплата, аккаунты, частные данные учеников и реальные клиентские записи не затрагиваются. Для тетради использовано только синтетическое содержимое в браузере проверяющего.

Нет оснований объединять все эти наблюдения в один «процент качества». Для тетради цепочка конкретна: незавершённая карточка не входит в сохраняемое состояние → общее сообщение создаёт неверное ожидание → после перезагрузки текст отсутствует. Альтернатива — намеренно отдельное сохранение карточки — объясняет архитектуру, но не снимает двусмысленность обратной связи. Для первого экрана улучшение понимания остаётся гипотезой; оценить его можно короткими заданиями новым посетителям, без выдуманных показателей конверсии.

## Проверка выпуска — отдельный этап

| Контроль | Статус этого пакета | Доказательство |
|---|---|---|
| Точный HEAD исправлений и неизменность перед выпуском | `NOT_RUN` | Добавить 40-символьный SHA; исходные наблюдения выше не переименовывать в новую версию. |
| `npm run check`, синтаксис сценариев, `git diff --check` | `NOT_RUN` | Добавить фактический результат. |
| Обязательный browser acceptance | `NOT_RUN` | Добавить run ID, attempt, HEAD, итог. |
| Обязательный Lighthouse | `NOT_RUN` | Добавить run ID, HEAD, итог; не выдавать лабораторные метрики за полевые. |
| Просмотр desktop/320/390 изображений | `NOT_RUN` | Привязать артефакт к run/HEAD и записать вывод. |
| Проверка 23 программ, источников изображений и ссылок | `NOT_RUN` | Зафиксировать результат регресса и ручной проверки. |
| Опубликованная версия | `NOT_RUN` | SHA merge, Pages run, сравнение публичных файлов и повторная проверка интерфейса. HTTP 200 недостаточно. |

Этот исторический пакет не обновляет старые наблюдения при каждой новой ревизии. Итоговые SHA, run ID, просмотр артефактов и публикация фиксируются в описании PR выпуска. Ответственный за следующий шаг — исполнитель изменений и независимый проверяющий. Завершение: точный HEAD проходит обязательные проверки, изображения просмотрены, текущий review не содержит блокирующих замечаний, а опубликованные файлы соответствуют проверенному дереву. При смене HEAD или неуспешной проверке следует исправить конкретный дефект и собрать актуальные доказательства; обходить gate нельзя.

## Что не доказано

Аудит не является сертификатом доступности, юридического соответствия или безопасности. Не проводились нагрузочные атаки, тесты физических телефонов, полноценная проверка скринридерами, исследование пользователей или измерение дохода/конверсии. Не утверждается отсутствие всех ошибок или равенство школы ведущим мировым брендам. Влияние изменений на бизнес — качественная гипотеза; видимые и функциональные результаты должны подтверждаться указанной проверкой выпуска.
