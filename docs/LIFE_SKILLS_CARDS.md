# AI PATH — новые визуальные карточки

Шесть оригинальных AI-изображений, встроенный инструмент Imagegen. На страницах есть подпись «AI-иллюстрация». Это вымышленные персонажи, а не реальные ученики или результаты ученических проектов.

Каждое изображение сохранено в `dist/ai-path/assets/life-skills/cards/KEY.webp` (960×640) и `KEY-thumb.webp` (320×213). Миниатюры используются в карточках уроков, основные версии — в заданиях и обложках. Оригиналы генерации сохранены отдельно без перезаписи.
