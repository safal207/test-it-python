# AI PATH: photographs and interactive lesson stages

The financial literacy course now presents each of its 18 age-specific lessons as Task → Explanation → Try → Check. The task starts with a fictional situation; the explanation keeps the original teaching material; practice uses a purchase basket, budget boxes, a minimum-period timeline, complete-cost comparison, suspicious-message signals or the checked final plan. Knowledge checks use two relevant hints and retain wrong selections for revision. The existing eight completion checks and saved version-1 progress are preserved.

This implementation uses browser-local progress and authored hints. It does not claim the adaptive platform, analytics or teaching service of the references below.

## Public references reviewed

- [Uchi.ru learning format](https://promo.uchi.ru/learning): short lessons, alternating activities, worked steps and guiding hints.
- [Foxford independent learning format](https://externat.foxford.ru/samostoyatelny): lessons, theory notes, interactive homework and progress together.
- [Foxford task feedback](https://foxford.ru/exams): automatic checks, hints and worked solutions.

Only the general learning patterns informed this design. The lesson text, activities, code and visual assets are independently authored for AI PATH.
