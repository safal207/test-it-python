# AI PATH: от примера к собственному проекту

Дата: 1 ноября 2026. Это описание подготовленной версии. Публикация и проверка удалённого CI подтверждаются отдельно.

## Проблема и новая последовательность

Старый путь заканчивался на демо или возвращал человека к общему выбору программ. Студия смешивала разработку и обучение, первый экран предлагал несколько равнозначных переходов, а каталог группировал проекты по месту размещения. Работы показывали возможности автора, но посетитель ещё должен был сам определить их пользу для своей задачи.

Новый путь: **понятная задача → подходящий работающий пример → план своей первой версии → выбранный формат помощи → осознанное обращение**.

- Студия начинает с результата — первой рабочей версии — и одного основного действия: собрать план. Кейсы показывают результат и действие, которым его можно проверить.
- Каталог сохраняет все 40 проектов и различает локальное демо, внешний сайт и материалы. Поверх этого добавлены шесть задач посетителя. У каждой карточки есть переход к своей идее с ID примера.
- 14 отдельных локальных демо получили конкретный следующий шаг. Для трёх встроенных практик переход доступен в каталоге; автономные версии уроков остаются автономными.
- Бесплатный конструктор выдаёт полезный результат до контакта: состав первой версии, критерии готовности, ограничения, связанный учебный маршрут и текст обращения. Регистрация и контактные данные не требуются.
- Разработка и обучение имеют разные следующие шаги. Исследовательские и учебные примеры не превращаются в обещание коммерческой разработки. Для книги, комикса и видео предусмотрены отдельные результаты.
- Письмо не отправляется с сайта. Человек видит текст, может изменить ответы, скачать или скопировать план и сам подтверждает отправку в своей почте.

## Применённые продуктовые принципы

В основу адаптации взяты ясное предложение и один основной призыв к действию из [ClickFunnels: Getting Started with Funnels](https://support.myclickfunnels.com/docs/getting-started-with-funnels/), а также постепенное увеличение полезности из [ClickFunnels: Sales Conversion Funnel](https://www.clickfunnels.com/blog/sales-conversion-funnel/). Для AI PATH первая полезность — проба и план собственного проекта. Это наша интерпретация принципов, а не интеграция с ClickFunnels и не обещание роста конверсии.

Не добавлялись вымышленные отзывы, продажи, скидки, обратные отсчёты, цены или гарантированные результаты. Наличие действующего учебного демо не представляется коммерческим внедрением.

## ИИ + Unity

По отдельному запросу пользователя добавляется 24-е направление с ID `unity`; прежние 23 сохраняются. Предлагаемая структура — 8 недель / 8 встреч с уточнением темпа и объёма до старта.

Первый учебный продукт: один небольшой 2D-уровень с управлением, предметами, условием победы и перезапуском. ИИ помогает объяснять код и формулировать проверки; ученик принимает решения и проверяет игру. Браузерная Game Lab остаётся пробой игровой логики, а не Unity-сборкой.

Материалы: презентация направления (10 слайдов), первый урок (12 слайдов), исходный скрипт движения и раздатка. На первом уроке цель уже: создать сцену и управляемого героя. Сбор предметов и победа относятся к последующим занятиям.

База материалов — Unity 6.3 LTS, новый Input System, `Rigidbody2D.linearVelocity`. Это выбранная версия для воспроизводимости, а не автоматически обновляемое утверждение о самой новой версии. Источники: [Unity releases/support](https://unity.com/releases/unity-6/support), [Input System installation](https://docs.unity3d.com/Packages/com.unity.inputsystem@1.14/manual/Installation.html), [Rigidbody2D.linearVelocity](https://docs.unity3d.com/6000.0/Documentation/ScriptReference/Rigidbody2D-linearVelocity.html).

## Что измерять после публикации

Сейчас нет подтверждённых данных о конверсии новой версии. Предлагаемые показатели после выбора и настройки аналитики:

| Переход | Что считать | Что это не доказывает |
|---|---|---|
| Вход → пример | Долю посетителей, начавших осмысленный сценарий | Успешное завершение демо |
| Пример → свой план | Долю переходов с сохранённым примером | Готовность покупать |
| План начат → план получен | Завершение трёх шагов | Отправленную заявку |
| План получен → скачан/скопирован | Использование результата | Контакт с наставником |
| Открыт почтовый черновик → получено письмо | Только подтверждённые поступившие обращения | Оплату или результат обучения |

Произвольный текст идеи не следует включать в события аналитики. В этой версии новые сторонние сборщики данных не подключены. A/B-эксперимент и улучшение конверсии пока не заявляются.

## Границы приёмки

Автоматическая проверка сайта может подтвердить переходы, состояние формы, выгрузку, отсутствие ошибок, адаптивность и программно обнаруживаемые проблемы доступности. Она не подтверждает доставку письма, коммерческую ценность, продажи или обучение реального ученика.

Отдельно нужны: запуск проекта в установленном Unity Editor; сборка под выбранную платформу; проверка на физическом телефоне для мобильного билда; ручной просмотр слайдов в целевой версии PowerPoint; отправка и получение реального согласованного обращения; наблюдение за новым пользователем при выборе направления.
