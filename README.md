## Публикация

GitHub Pages публикует папку `dist` после каждого обновления `main`.
Настройка находится в `.github/workflows/pages.yml`.
Уроки, редактор, проверка решений и проекты работают без входа в аккаунт.

При переходе с другого адреса сайта перенеси прогресс через раздел
«Прогресс»: сначала скачай JSON на старом адресе, затем загрузи на новом.
Браузер хранит данные для каждого адреса отдельно.

## Запуск сайта

Node.js: node server.mjs, затем http://127.0.0.1:5186.
Статические файлы в dist. Сборка и npm-зависимости не нужны.
Python выполняется в module Web Worker через Pyodide 314.0.7 с CDN jsDelivr.
Первый запуск требует интернета; pytest загружается по необходимости, SQLite входит в среду Python.
Каждый запуск изолирован в новом worker. Остановка/тайм-аут завершают worker.
Проверки учебные, не защищённая система экзаменационной оценки.

Прогресс сохраняется только в localStorage. Экспорт/импорт JSON переносит
уроки, задачи, черновики и повторение. Проектные чек-листы — самооценка.

starter — исходники учебного проекта, dist/qa-starter.zip — скачиваемый архив.
Сервер магазина слушает только loopback. Инструкции — в starter/README.md.
Ссылки на официальную документацию размещены в уроках.
